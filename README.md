# NodeSpace

NodeSpace 是一个本地优先的节点网络图应用：记下一条想法，连接相关节点，逐步整理成自己的知识网络。

它不是 Obsidian 的替代品。Markdown 与附件可以继续由 Obsidian 管理，NodeSpace 负责空间组织、跨空间导航和不同信息粒度下的观察。

## 从一张简单的图开始

- 主界面用全幅图封面浏览空间。可拖动、滚动或用左右方向键移动，到实际首尾停止。点击封面或从「文件树」打开空间。
- 从画布点「主界面」或在空闲时按 `Esc`，回到刚才浏览的位置。画布的「文件树」可切换空间，「分屏」可添加窗格。「工具」提供快速记录、打开资料库和恢复备份。
- 点击“+ 记录”或按 `N` 新建节点，直接输入名称，按需补充笔记。
- 正文自动保存，`Enter` 换行，`Ctrl / ⌘ + Enter` 完成输入；一次连续编辑可一次撤销。媒体收在“附件”中，颜色与大小收在“节点外观”中。
- 点击“连线”连接两个节点；桌面端也可以在节点间右键拖拽连线。
- 已选中节点时，“连线”会直接以它为起点；点击空白处可以创建已连接的新想法。桌面端也可以把右键连线拖向空白处来长出分支。
- 选中连线可编辑关系说明、箭头和方向，颜色与线型收在“显示样式”中。切换箭头或交换方向均可撤销。
- 选中节点按 `Tab` 新建子节点，按 `Delete` 删除，按 `Ctrl+Z` 撤销。
- 按 `Ctrl / ⌘ + D` 创建所选节点的副本；从菜单粘贴多节点时，内部连线随节点一起复制，整批可以一次撤销。
- 按 `Ctrl / ⌘ + F` 搜索当前空间，用上下方向键预览结果，按 `Enter` 定位并打开笔记。再次进入搜索可用 `Enter` / `Shift+Enter` 继续向后或向前查找。
- 集合搜索也支持上下键、`Enter` 与 `Esc`；新集合保留名称大小写，并从当前主题取色。只读空间可以查找集合。
- 默认显示节点和明确连线；在“视图”中可切换阅读卡片、自适应、树形、星型等方式。
- 默认自动排布；需要自行摆放时，可切换自由布局并固定节点。

## 产品原则

- 记录优先：标签、分类和布局选择都不是开始记录的前置条件。
- 内容与视图分离：卡片和节点是同一条内容在不同缩放与场景下的表现。
- 节点与连线优先：先把记录、连接、查找和浏览做好，再逐步完善其他能力。
- 来源必须可辨认：用户关系、原文引用、结构关系和文字线索分别呈现。
- 排布不改写关系：文字匹配只辅助排布，不写成真实连线；节点视图隐藏文字线索与区域。
- 本地计算：自动整理使用连线、层级和确定性的文字匹配，无需模型服务，也不发送笔记内容。
- 审美与设计：默认使用“纸白 · 暖陶”，以暖纸、暖墨文字和陶土色组织画面。保留空间感与细腻反馈，让光影与动效服务阅读、关系和方向感。

## 外观与空间感

在“外观 → 空间主题”中切换配色。每张图保留自己的选择，新空间默认使用“纸白 · 暖陶”。画布、工作台、网格、关系线和界面共享主题配置，画布字体可独立选择。

“纸白 · 暖陶”与“Claude · 暖夜”分别取自 Obsidian 的 Claude 浅色和暗色。两套主题的“分级”节点配色对应原配色的 H1–H6，外观面板可预览。

节点和关系的颜色可选择“跟随主题”，也可从柔和预设或自定义颜色中指定。已有配色继续保留；手动指定的关系色优先于渐变设置，恢复主题色也支持撤销与重做。

空白画布从一个可直接点击的想法入口开始。节点与连线支持逐步生长，创建一条分支可一次撤销。布局过渡尊重系统的“减少动态效果”偏好。

“适配全部”按当前可见节点的最终位置取景，折叠内容不占用视野。节点视图使用更紧凑的留白，短标题在中等缩放下保持可读；阅读卡片保留摘要与区域标题所需的空间。

节点网络视图中，编辑面板展开时会轻轻平移被遮挡的所选节点或关系端点，保持当前缩放。对象已经可见时不移动；手动拖动或滚动画布后，由用户接管视角。

撤销和重做会恢复当时的排布；内容与显示粒度没有变化时，重新打开也保留已有节点位置。主题与字体由外观设置独立管理。

节点大小可在“节点外观”中按等级或自定义半径调整。大小会同步到排布、连线端点与点击范围，一次连续调整可一次撤销。

通过“工具 → 导入多媒体”或将文件拖到目标窗格，可以导入图片、音视频、PDF 和文本；整批导入可一次撤销。文本直接保存正文，桌面端的媒体保留原文件路径。浏览器媒体保存在当前站点的 IndexedDB 中，重开仍可读取，也不会挤占图 JSON 的 localStorage 配额。浏览器附件随当前设备与站点保存，跨设备移动图 JSON 时需重新选择原文件；清除站点数据也会清除这些附件。

节点的“附件 → 查看附件”可直接进入阅读器。文档可以在阅读与编辑间切换，保留 Markdown 原文和空白；一次连续编辑可一次撤销。阅读器始终写回打开时的节点，切换窗格不会把内容写入主图，来源变化后也不会覆盖新内容。

## 数据与平台

图文件目前使用：

```text
{ nodes: [], edges: [], groups: [], settings: {} }
```

桌面端使用 Electron，移动端使用 Capacitor Android，画布由 PixiJS 8 渲染。默认采用静态自动排布，D3 力导向作为可选观察方式。已有图文件与显式保存的视图偏好继续兼容。

桌面文件变更以系统监听为主，用异步元数据轮询补查遗漏的新增、修改和删除。轮询限制并发并合并重叠请求，只读取文件信息，不改写 Markdown 与附件；暂时无法访问的目录不会被误报为内容已删除。

“工具 → 导出备份”保存当前图、视图设置和可读取的应用内附件。可从工具菜单或工作台恢复到新空间。Vault 路径、桌面媒体路径和跨空间引用在备份中保留为待重新关联的信息。

当打开的目录是 Obsidian Vault 时：

- 图专用文件夹由用户在“应用与默认值 → 资料库 → 图文件夹”中指定，新资料库默认为 `./NodeSpace`；
- 旧版本已经使用的图目录会保留，不会自动移动文件；
- 主界面保留所有 NodeSpace 图，并以单个 Obsidian 入口按目录浏览笔记和附件。
- 桌面端可编辑 Markdown 原文和投影中的章节标题、正文。编辑区实时渲染 Markdown 及公式，保存写回 `.md` 文件。

## 开发

```bash
npm ci
npm run dev
npm run check
```

用 `npm run electron:build` 构建本地桌面安装包，产物在 `release/`。Android 构建需要 JDK 21 与 Android SDK API 36，运行 `npm run android:build` 生成 `android/app/build/outputs/apk/debug/app-debug.apk`。

项目也包含一个可选 MCP Server，用于外部工具读写本地图文件，不参与应用排布。详见 `mcp-server/AGENT_INSTRUCTIONS.md`。

## 后续迭代方向

围绕“记录 → 连线 → 浏览 → 找回”的基本流程持续完善：优先保证编辑与撤销可靠、布局稳定、节点文字清晰、大图浏览流畅，并保持桌面与移动端的操作一致。
